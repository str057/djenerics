# Программа учета товаров и категорий

## Описание

Это программа на Python для учета товаров в различных категориях. Реализована система классов для представления продуктов, смартфонов, газонной травы и категорий товаров.

## Классы

### 1. Базовый класс Product

Базовый класс для всех продуктов с общими свойствами:
- `name` - название товара
- `description` - описание
- `price` - цена
- `quantity` - количество на складе

Методы:
- `__add__` - позволяет складывать цены товаров одного типа

### 2. Класс Smartphone (наследуется от Product)

Дополнительные свойства:
- `efficiency` - показатель эффективности
- `model` - модель
- `memory` - объем памяти
- `color` - цвет

### 3. Класс LawnGrass (наследуется от Product)

Дополнительные свойства:
- `country` - страна-производитель
- `germination_period` - срок прорастания
- `color` - цвет

### 4. Класс Category

Для группировки товаров по категориям:
- `name` - название категории
- `description` - описание категории
- `products` - список товаров в категории

Статическое свойство:
- `product_count` - общее количество товаров во всех категориях

Методы:
- `add_product()` - добавление товара в категорию

## Пример использования

Программа демонстрирует:
1. Создание экземпляров товаров
2. Вывод информации о товарах
3. Сложение цен товаров одного типа
4. Обработку ошибок при сложении разных типов товаров
5. Работу с категориями:
   - Создание категорий
   - Добавление товаров
   - Подсчет общего количества товаров
